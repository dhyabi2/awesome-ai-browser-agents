# Contributing to Awesome AI Browser Agents

Thank you for wanting to contribute! This list is maintained by the community.

## How to Add a New Entry

1. Fork this repository
2. Add your entry in alphabetical order within the appropriate section
3. Follow the formatting guidelines below
4. Open a pull request with a brief description

## Formatting Guidelines

Each entry should follow this format:

```
- [Tool Name](https://link.to/tool) — One-sentence description of what it does and why it's relevant.
```

- Use `—` (em dash) to separate the name from the description
- Descriptions should be concise (under 100 characters if possible)
- Focus on what makes the tool useful for AI browser agents specifically
- No trailing period

## Requirements for New Entries

1. **Relevance**: Must be specifically useful for AI agent browser automation
2. **Quality**: Must have documentation (README at minimum)
3. **Maintenance**: Must have activity within the last 12 months
4. **Stars**: For open source projects: 50+ stars OR exceptional niche value
5. **No duplicates**: Check if similar tools are already listed

## What We Accept

✅ Cloud browser platforms and APIs  
✅ Browser automation frameworks (Puppeteer, Playwright, etc.)  
✅ MCP servers for browser control  
✅ AI agent frameworks with browser capabilities  
✅ Anti-detection and proxy tools  
✅ Learning resources (tutorials, guides, courses)  

## What We Don't Accept

❌ Commercial-only tools with no free tier or documentation  
❌ Abandoned projects (no activity in 12+ months)  
❌ Generic web development tools (unless strongly AI-agent relevant)  
❌ Self-promotion without genuine community value  

## Section Guidelines

If your tool doesn't fit any existing section, suggest a new section in your PR with at least 3 entries to populate it.

## Questions?

Open an issue to discuss additions or changes before submitting a PR.
